# Сектор, вторая станция и доставка 0.7

Согласовано: вторая станция, карта сектора, перевозка груза между станциями. Создаём станцию «Полигон» (существующая) и аванпост «Вектор», общий сектор и третье задание «Доставка». Груз — один учебный контейнер с оборудованием, загружается автоматически при принятии, сдаётся при стыковке на другой станции. Вознаграждение 220 кредитов, без предоплаты и без врагов на маршруте. Доступна обратная доставка.

Карта XZ: две станции, учебный маяк, корабль, текущая цель. Выбор станции на карте показывает её название/расстояние, карта приостанавливает полёт; закрытие возвращает управление. Наведение на цель остаётся ручным, телепортация не вводится. Стыковка: прежние ≤14 м от точки и ≤5 м/с, на неправильной станции доставки нет. По завершении текущая станция меняется, меню/ремонт/модули доступны уже там.

Сохранения: метаданные station_id и снимок версии 2 с origin/destination/cargo. Снимки версии 1 из 0.6 принимаются с исходной станцией 0. Контейнер и маршрут восстанавливаются; награда только один раз, груз удаляется при сдаче. Отмена активного задания по существующему подтверждению без награды.

Проверки: перелёт в обе стороны без телепортации, неверная станция/скорость, награда и удаление груза, повторная стыковка, продолжение посреди перевозки, миграция снимков 0.6, карта и пауза, мобильные ориентации, прежние тесты, экспорт APK.
