# Проверка версии 0.1.1

Движок: Godot 4.5.1 official.

Исправлены: ошибка вывода типа target_velocity, блокирующая загрузку скрипта; настройка импорта мобильных текстур, блокирующая Android экспорт. Движок обновлён с 4.4.1 до 4.5.1 для совместимости нативных Android библиотек со страницами 16 КБ.

10 проверок smoke.gd пройдены. Проект импортируется и запускается без ошибок GDScript. Обе камеры отрисованы и визуально просмотрены в Linux OpenGL. APK экспортирован для arm64-v8a. Подпись APK проверена apksigner. Устройство Android и замеры производительности отсутствуют; подключение к adb недоступно.

Проверки не подтверждают корректность мультитача на физическом устройстве, тепловую устойчивость и полноту сохранений в условиях принудительного завершения Android.
