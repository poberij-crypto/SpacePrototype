# Ship armament and station weapon shop

Implement the approved first set of interchangeable weapons. Skif has two main mounts and an independent missile launcher. A shared held-fire control fires the selected group (both, left, right); missiles use an independent lock-and-launch action. Weapon shop supports buying, selling, fitting, removing and replenishing ammunition on docked stations, with station-local storage. Profile and flight snapshots migrate old laser upgrades and retain credits/cargo. The same package includes the previously requested automatic horizon leveling on planetary surfaces.

- Add an armament state with weapon catalog, compatible mounts, power budget, stock, ammo, energy, per-mount heat/cooldown and flight group.
- Integrate laser damage, cannon/plasma projectiles, missile target lock/guidance, enemy shields and appropriate projectile effects; persist combat state and projectiles across flight resumes.
- Add station shop and flight controls/readouts within the approved corner HUD; test normal entry points and failed writes.
- Add surface horizon leveling, preserving heading and active steering.
- Run regression tests, inspect rendered UI, export signed APK, publish sources to the existing feature branch.

Initial balance is an implementation choice. Weapons are available as laser, cannon, plasma and missile launcher, with different station prices. The starter ship retains two basic lasers and inherits existing weapon upgrade strength. Energy cap100 and equipment power limit70 provide a trade-off for heavier loadouts. Ammo stocks and weapon storage are separate from the commercial cargo hold.
