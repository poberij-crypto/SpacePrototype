# Проверка 0.3.0

- Импорт Godot 4.5.1 и запуск сцены: без ошибок скриптов.
- smoke.gd: десять проверок механик пройдены.
- ui_test.gd: масштабирование координат, независимый второй палец для стрельбы, отпускание управления и меню пройдены.
- visuals_test.gd: видимость внешнего корабля/кабины, изменение выхлопа с тягой, создание эффектов, лимит 48 и завершение эффектов пройдены.
- Отрисованы внешний вид, кабина и выстрел в OpenGL Compatibility. Ошибок компиляции шейдеров нет. Предупреждение VSync относится к программному драйверу окружения.
- Исправлено обращение к освобождённому эффекту при раннем удалении из очереди. Время жизни дополнено минимальным числом кадров, чтобы лучи не исчезали до отрисовки на медленных кадрах.
- Экспорт ARM64 APK выполнен с прежним тестовым ключом и пакетом org.dmitry.spaceprototype.ui.

Физического Android устройства для проверки не было. Производительность на телефоне и долгие сессии не измерены. Максимум эффектов ограничивает их накопление, но сам по себе не гарантирует стабильную частоту кадров.
